# API Demo 项目  
一个基于 Spring Boot 的简单 REST API 演示项目，包含基础的 `/hello` 接口功能。  


## 项目简介  
本项目用于展示 Spring Boot 开发 RESTful API 的基础流程，目前已实现 `/hello` 接口，支持返回 JSON 格式的问候信息。后续可基于此扩展更多业务接口。  


## 技术栈  
- **框架**：Spring Boot 3.2.9  
- **开发语言**：Java 17  
- **构建工具**：Maven  
- **依赖管理**：Spring Web（核心 Web 功能）、Lombok（简化代码）  


## 快速开始  

### 环境要求  
- JDK 17 及以上  
- Maven 3.6+ 或 IDE 集成的 Maven 环境
